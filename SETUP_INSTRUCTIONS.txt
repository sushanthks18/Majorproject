ISSUE 1: Connection Refused Error
-----------------------------------
You need to update the server URL in your code.

STEP 1: Find Your Computer's IP Address
   On Windows:
   - Press Win + R
   - Type: cmd
   - Press Enter
   - Type: ipconfig
   - Look for "IPv4 Address" (e.g., 192.168.1.100)

STEP 2: Update the ESP32 Code
   Open: esp32_sensor_client.ino
   
   Change line 38-39:
   FROM: const char* ssid = "YOUR_WIFI_SSID";
   TO:   const char* ssid = "YourActualWiFiName";
   
   FROM: const char* password = "YOUR_WIFI_PASSWORD";
   TO:   const char* password = "YourActualPassword";
   
   Change line 44:
   FROM: const char* serverUrl = "http://YOUR_SERVER_IP:5001/api/sensors/data";
   TO:   const char* serverUrl = "http://192.168.1.100:5001/api/sensors/data";
         (Replace 192.168.1.100 with YOUR computer's IP)

STEP 3: Start the Backend Server
   Open terminal/command prompt in the project folder:
   
   cd backend
   npm install
   npm run dev
   
   Wait for: "Server running on port 5001"

STEP 4: Re-upload Code to ESP32
   - Click Upload in Arduino IDE
   - Wait for completion
   - Open Serial Monitor (115200 baud)


ISSUE 2: LCD Display Blank
----------------------------
STEP 1: Install LCD Library
   - Arduino IDE → Tools → Manage Libraries
   - Search: "LiquidCrystal I2C"
   - Install: "LiquidCrystal I2C by Frank de Brabander"

STEP 2: Hardware Connection (I2C LCD 16x2)
   LCD Pin → ESP32 Pin
   -------    ---------
   GND     →  GND
   VCC     →  5V (or 3.3V)
   SDA     →  GPIO 21 (SDA)
   SCL     →  GPIO 22 (SCL)

STEP 3: Check I2C Address (if LCD still blank)
   Upload this test code to check LCD address:
   
   #include <Wire.h>
   void setup() {
     Wire.begin();
     Serial.begin(115200);
     Serial.println("I2C Scanner");
   }
   void loop() {
     byte error, address;
     for(address = 1; address < 127; address++) {
       Wire.beginTransmission(address);
       error = Wire.endTransmission();
       if (error == 0) {
         Serial.print("I2C device at 0x");
         Serial.println(address, HEX);
       }
     }
     delay(5000);
   }
   
   Common addresses: 0x27, 0x3F
   If you find different address, update line 64 in esp32_sensor_client.ino

STEP 4: Re-upload Main Code
   - Upload esp32_sensor_client.ino
   - LCD will show rotating data every 2 seconds


LCD DISPLAY MODES (Auto-rotating every 2 seconds):
---------------------------------------------------
Screen 1: Temperature & Humidity
Screen 2: Soil Moisture & pH
Screen 3: Rain Level & WiFi Status


COMPLETE HARDWARE CONNECTIONS:
-------------------------------
DHT22:
  VCC  → 3.3V
  DATA → GPIO 4
  GND  → GND

Soil Moisture Sensor:
  VCC  → 3.3V
  AOUT → GPIO 34
  GND  → GND

pH Sensor:
  VCC  → 5V or 3.3V
  AOUT → GPIO 35
  GND  → GND

Rain Sensor:
  VCC  → 3.3V or 5V
  AOUT → GPIO 32
  GND  → GND

LCD 16x2 I2C:
  VCC  → 5V or 3.3V
  GND  → GND
  SDA  → GPIO 21
  SCL  → GPIO 22


TROUBLESHOOTING:
----------------
1. LCD blank? → Check I2C address, try 0x3F instead of 0x27
2. Connection refused? → Start backend server first
3. WiFi not connecting? → Use 2.4GHz WiFi, not 5GHz
4. No Serial output? → Set baud rate to 115200
