═══════════════════════════════════════════════════════════════
  STEP 4: SETUP ESP32 MICROCONTROLLER
═══════════════════════════════════════════════════════════════

INSTALL ARDUINO IDE & LIBRARIES
--------------------------------
1. Download Arduino IDE:
   → https://www.arduino.cc/en/software
   → Install the latest version

2. Install ESP32 Board Support:
   → Open Arduino IDE
   → File → Preferences
   → Additional Board Manager URLs, add:
     https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   → Tools → Board → Boards Manager
   → Search "esp32" and install "esp32 by Espressif"

3. Install Required Libraries:
   → Tools → Manage Libraries
   → Install these libraries:
     ✓ ArduinoJson by Benoit Blanchon
     ✓ DHT sensor library by Adafruit
     ✓ Adafruit Unified Sensor
     ✓ LiquidCrystal I2C by Frank de Brabander


CONFIGURE & UPLOAD CODE
------------------------
1. Open esp32_sensor_client.ino in Arduino IDE

2. Update WiFi Credentials (Lines 38-39):
   const char* ssid = "YOUR_WIFI_NAME";
   const char* password = "YOUR_WIFI_PASSWORD";

3. Update Server URL (Line 44):
   → First, find your computer's IP address:
     - Open Command Prompt
     - Type: ipconfig
     - Look for "IPv4 Address" (e.g., 192.168.1.100)
   
   → Update the code:
   const char* serverUrl = "http://192.168.1.100:5001/api/sensors/data";
   (Replace 192.168.1.100 with YOUR IP)

4. Select Board:
   → Tools → Board → ESP32 Dev Module

5. Select Port:
   → Connect ESP32 via USB
   → Tools → Port → (Select your COM port)

6. Upload Code:
   → Click Upload button (→)
   → Hold BOOT button on ESP32 when "Connecting..." appears
   → Wait for "Done uploading"

7. Open Serial Monitor:
   → Tools → Serial Monitor
   → Set baud rate to: 115200
   → Press RESET button on ESP32
   → You should see sensor data being sent!


═══════════════════════════════════════════════════════════════
  STEP 5: HARDWARE CONNECTIONS
═══════════════════════════════════════════════════════════════

DHT22 Temperature & Humidity Sensor
------------------------------------
  DHT22 Pin  →  ESP32 Pin
  VCC        →  3.3V
  DATA       →  GPIO 4
  GND        →  GND


Capacitive Soil Moisture Sensor
--------------------------------
  Sensor Pin  →  ESP32 Pin
  VCC         →  3.3V
  AOUT        →  GPIO 34
  GND         →  GND


pH Sensor Module
----------------
  Sensor Pin  →  ESP32 Pin
  VCC         →  5V or 3.3V
  AOUT        →  GPIO 35
  GND         →  GND


Rain Sensor
-----------
  Sensor Pin  →  ESP32 Pin
  VCC         →  3.3V or 5V
  AOUT        →  GPIO 32
  GND         →  GND


LCD Display 16x2 I2C
---------------------
  LCD Pin  →  ESP32 Pin
  VCC      →  5V or 3.3V
  GND      →  GND
  SDA      →  GPIO 21
  SCL      →  GPIO 22

═══════════════════════════════════════════════════════════════
  HOW THE SYSTEM WORKS
═══════════════════════════════════════════════════════════════

1. ESP32 reads sensors every 10 seconds:
   → DHT22: Temperature & Humidity
   → Soil Moisture: Moisture level
   → pH Sensor: Soil pH
   → Rain Sensor: Rain detection

2. ESP32 sends data to Backend via WiFi:
   → POST request to: http://YOUR_IP:5001/api/sensors/data
   → JSON format with all sensor readings

3. Backend saves data and broadcasts:
   → Stores in database (if MongoDB is running)
   → Broadcasts via Socket.io to all connected clients

4. Frontend receives real-time updates:
   → Dashboard auto-updates with new sensor data
   → No page refresh needed
   → Live graphs and statistics

5. Crop Recommendation:
   → Uses current sensor data
   → Applies ML model or rule-based system
   → Returns best crop suggestions
   → Shows confidence and detailed analysis

═══════════════════════════════════════════════════════════════
  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

WEBSITE ISSUES
--------------
❌ "npm is not recognized"
   → Install Node.js from https://nodejs.org

❌ Backend won't start
   → Make sure port 5001 is not in use
   → Check .env file exists in backend folder

❌ Frontend won't start  
   → Make sure port 5173 is not in use
   → Run: npm install in frontend folder


ESP32 ISSUES
------------
❌ "Connection refused" in Serial Monitor
   → Check server URL has correct IP address
   → Make sure backend is running
   → Verify ESP32 and computer on same WiFi network

❌ Code won't upload to ESP32
   → Install ESP32 board support in Arduino IDE
   → Select correct board and COM port
   → Hold BOOT button during upload

❌ LCD is blank
   → Check I2C connections (SDA → 21, SCL → 22)
   → Install LiquidCrystal I2C library
   → Try address 0x3F instead of 0x27 (line 64 in code)

❌ No sensor readings
   → Check sensor wiring
   → Verify power connections (VCC and GND)
   → Check DHT22 library is installed


WEBSITE NOT SHOWING LIVE DATA
------------------------------
❌ Dashboard shows old data
   → Check ESP32 Serial Monitor - is it sending data?
   → Verify backend is receiving data (check backend logs)
   → Refresh browser page
   → Check browser console for errors

❌ Crop recommendation not working
   → Make sure sensor data is available
   → Click "Get Recommendation" button
   → Check backend logs for errors
